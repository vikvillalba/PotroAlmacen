# Definition of Done

Una task se considera **terminada** solo cuando cumple todos los criterios siguientes.

## 1. Alcance del ticket de Jira

- La rama y su pull request corresponden a **un solo ticket de Jira**.
- El trabajo abarca **completamente** lo que pide el ticket.
- No se incluye trabajo de otros tickets en la misma rama o PR. Si surge algo fuera del alcance,
  se crea (o se usa) otro ticket con su propia rama y PR.

## 2. Pull request aprobado

- El PR fue **revisado y aprobado por uno o más integrantes del equipo** distintos al autor.
- Los comentarios de la revisión fueron atendidos o resueltos antes de hacer merge.

## Checklist

Antes de mover el ticket a *Done*:

- [ ] La rama y el PR cubren un único ticket de Jira.
- [ ] Se completó todo lo que pide el ticket.
- [ ] El PR tiene al menos una aprobación de otro integrante del equipo.
- [ ] Los comentarios de la revisión están resueltos.
