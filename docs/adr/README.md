# Architecture Decision Records (ADR)

Cada ADR documenta una decisión de arquitectura: el contexto, las opciones y lo que se decidió.

- Nombre del archivo: `NNNN-titulo-corto.md`, con número consecutivo.
- Estados: **Pendiente** (aún no se decide), **Aceptado**, **Rechazado** o **Reemplazado por ADR NNNN**.
- Un ADR aceptado no se edita: si la decisión cambia, se escribe uno nuevo que lo reemplace.
